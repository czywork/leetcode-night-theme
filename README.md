# 深夜护眼 · 力扣夜间主题

给 [力扣 leetcode.cn](https://leetcode.cn) 做的暖色深夜护眼主题，Edge / Chrome 都能装。

力扣本身没有主题切换入口，内置的暗色偏冷（蓝灰），夜里盯久了眼睛发涩。这个扩展把整套配色换成**暖炭黑 + 象牙白 + 琥珀强调**，并把代码高亮一并换了色 —— 不是简单套一层滤镜，而是直接接管力扣自己的设计变量。

---

## 效果

| 项目 | 官方浅色 | 本主题 |
| --- | --- | --- |
| 页面底色 | `#ffffff` | `#16120f`（暖炭黑） |
| 面板 | `#ffffff` | `#221d19` |
| 代码区 | `#ffffff` | `#1b1714` |
| 正文 | `#1a1a1a` | `#ede4d8`（象牙白） |
| 强调色 | `#ffa116` | `#e9a94f`（柔化琥珀） |

代码高亮的语法色全部重新映射过，注释、关键字、数字、函数名在暖黑底上都满足 WCAG AA 对比度。

## 安装

扩展没有上架商店，本地加载即可（Edge 和 Chrome 步骤一样）：

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`）
2. 地址栏打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
3. 打开左下 / 右上角的 **开发人员模式**
4. 点 **加载解压缩的扩展**，选择本仓库根目录（含 `manifest.json` 的那一层）
5. 打开任意力扣页面，主题自动生效

> 更新版本后，记得在扩展页面点一下 **刷新** 图标。

## 使用

点浏览器工具栏的月亮图标打开面板：

- **总开关** —— 一键开 / 关
- **暖色强度**（0–100）—— 叠一层暖光，越低越接近原生冷色，越高越黄
- **再压暗一点**（0–60）—— 适合深夜 / 关灯场景
- **预设** —— 标准夜 / 柔和 / 极护眼，一档到位

### 快捷键

| 组合 | 作用 |
| --- | --- |
| `Alt` + `Shift` + `N` | 开关主题 |
| `Alt` + `Shift` + `↑` / `↓` | 暖色强度 ±5 |
| `Alt` + `Shift` + `←` / `→` | 压暗程度 ±5 |

关掉主题后会**完整还原**力扣原本的样子（包括你原本用的是浅色还是深色），不会留下半截冷灰。

## 实现思路

力扣的配色并不靠逐个写死，而是走一套语义化 CSS 变量：

```css
/* 站点自己就有两套映射：亮色 :root，暗色 html.dark */
:root      { --layer-01: #fff;   --text-primary: #1a1a1a; }
html.dark  { --layer-01: #262626; --text-primary: #f5f5f5; }
```

所以这个扩展的核心只有一句：**把整套语义变量重新映射到暖色**，所有面板、弹窗、下拉、表格会自动跟着变。

```css
html[data-lc-night='on'] {
  --layer-01: #221d19;
  --text-primary: #ede4d8;
  /* … 共约 200 个变量 */
}
```

选择器用 `html[data-lc-night='on']`（特指度 0,1,1）压过站点的 `:root`（0,1,0）。**用 data 属性而不是 class 挂载**是有原因的：力扣会执行 `el.className = 'light'` 整体重写 class，挂在 class 上的自定义标记会被连带清掉，属性则不受影响。

两个必须单独处理的坑：

1. **Monaco 编辑器**锁死在浅色 `vs` 主题，32 个语法令牌色（`.mtk1` ~ `.mtk32`）是硬编码的，改不了变量，只能逐个覆盖。
2. **题面代码块**用 Prism，颜色写在行内 `style="color: slategray"` 里，得靠属性选择器 `[style*='slategray']` 才能命中。

另外还有一批只带 `text-label-*` 而没有对应 `dark:` 变体的文字，是浅色主题的深灰，压在暖黑上对比度只有 1.2 —— 这类也单独兜底了。

## 文件结构

```
leetcode-night-theme/
├── manifest.json        # MV3 清单
├── icons/               # 16/32/48/128 图标
└── src/
    ├── theme.css        # 主题本体（变量映射 + 兜底 + 代码高亮）
    ├── content.js       # 挂载/守护、遮罩、快捷键、设置同步
    ├── popup.html       # 设置面板
    ├── popup.css
    ├── popup.js
    └── background.js    # 快捷键命令、安装初始化
```

## 已知边界

- 只覆盖力扣，没有适配其他 OJ
- 题库页的运营 Banner 是图片素材，不受配色影响（那是品牌图，不打算改）
- 站点改版动了颜色体系的话，可能需要重新对齐一轮变量
