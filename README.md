# 深夜护眼 · 力扣夜间主题

给 [力扣 leetcode.cn](https://leetcode.cn) 做的暖色深夜护眼主题，Edge / Chrome 都能装。

力扣本身没有主题切换入口，内置的暗色偏冷（蓝灰），夜里盯久了眼睛发涩。这个扩展把整套配色换成**暖炭黑 + 象牙白 + 琥珀强调**，并把代码高亮一并换了色 —— 不是简单套一层滤镜，而是直接接管力扣自己的设计变量。

---

## 效果

| 项目 | 官方浅色 | 本主题 |
| --- | --- | --- |
| 页面底色 | `#ffffff` | `#16120f`（暖炭黑） |
| 面板 | `#ffffff` | `#221d19` |
| 代码区 | `#ffffff` | `#1b1714` |
| 正文 | `#1a1a1a` | `#ede4d8`（象牙白） |
| 强调色 | `#ffa116` | `#e9a94f`（柔化琥珀） |

代码高亮的语法色全部重新映射过，注释、关键字、数字、函数名在暖黑底上都满足 WCAG AA 对比度。

### 四套配色主题

点月亮按钮打开面板，一键切换：

| 主题 | 底色 | 风格 |
| --- | --- | --- |
| **暖夜琥珀** | `#16120f` | 默认。暖炭黑，蓝光最少，适合深夜 |
| **护眼墨绿** | `#0f1613` | 绿灰底，压蓝光但画面不发绿失真 |
| **Solarized** | `#002b36` | 2011 年的经典护眼配色，青蓝底 |
| **Gruvbox** | `#282828` | 复古暖调，语法色区分度高，写代码舒服 |

快捷键 `Alt + Shift + T` 循环切换主题。

> 为什么不做「纯绿」：纯绿大底会让所有颜色失真，长时间看反而更累，
> 也会让「简单」难度标签（绿色）和背景融在一起。这里用的是**绿灰**。

## 安装

两种方式，效果完全一样，任选其一。

### 方式一：油猴脚本（推荐，最省事）

1. 装用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. **新版篡改猴（MV3）需要手动允许用户脚本**：打开 `edge://extensions/` → 篡改猴「详细信息」→ 打开「允许用户脚本」
3. 安装脚本，两种办法任选：
   - 下载 [`userscript/leetcode-night-theme.user.js`](./userscript/leetcode-night-theme.user.js)，拖进篡改猴的管理面板
   - 或在篡改猴管理面板 →「实用工具」→ 导入该文件
4. 打开任意力扣页面，主题自动生效

> ⚠️ `raw.githubusercontent.com` 在国内经常不可达，所以脚本**没有配置 `@updateURL` 自动更新**（否则会反复更新失败弹错）。
> 需要更新时，重新下载本文件导入即可覆盖旧版，设置不会丢。

### 方式二：浏览器扩展

扩展没有上架商店，本地加载即可（Edge 和 Chrome 步骤一样）：

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`）
2. 地址栏打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
3. 打开左下 / 右上角的 **开发人员模式**
4. 点 **加载解压缩的扩展**，选择本仓库根目录（含 `manifest.json` 的那一层）
5. 打开任意力扣页面，主题自动生效

> 更新版本后，记得在扩展页面点一下 **刷新** 图标。

## 使用

**扩展版**：点浏览器工具栏的月亮图标。
**油猴版**：点页面右下角的月亮悬浮按钮，或从脚本管理器的菜单里打开。

面板里可以：

- **总开关** —— 一键开 / 关
- **暖色强度**（0–100）—— 叠一层暖光，越低越接近原生冷色，越高越黄
- **再压暗一点**（0–60）—— 适合深夜 / 关灯场景
- **配色主题** —— 四套主题点选切换（见上方表格）
- **预设** —— 标准夜 / 柔和 / 极护眼，一档调好暖度与亮度

### 快捷键

| 组合 | 作用 |
| --- | --- |
| `Alt` + `Shift` + `N` | 开关主题 |
| `Alt` + `Shift` + `↑` / `↓` | 暖色强度 ±5 |
| `Alt` + `Shift` + `←` / `→` | 压暗程度 ±5 |
| `Alt` + `Shift` + `T` | 循环切换配色主题 |

关掉主题后会**完整还原**力扣原本的样子（包括你原本用的是浅色还是深色），不会留下半截冷灰。

## 实现思路

力扣的配色并不靠逐个写死，而是走一套语义化 CSS 变量：

```css
/* 站点自己就有两套映射：亮色 :root，暗色 html.dark */
:root      { --layer-01: #fff;   --text-primary: #1a1a1a; }
html.dark  { --layer-01: #262626; --text-primary: #f5f5f5; }
```

所以这个扩展的核心只有一句：**把整套语义变量重新映射到暖色**，所有面板、弹窗、下拉、表格会自动跟着变。

```css
html[data-lc-night='on'] {
  --layer-01: #221d19;
  --text-primary: #ede4d8;
  /* … 共约 200 个变量 */
}
```

选择器用 `html[data-lc-night='on']`（特指度 0,1,1）压过站点的 `:root`（0,1,0）。**用 data 属性而不是 class 挂载**是有原因的：力扣会执行 `el.className = 'light'` 整体重写 class，挂在 class 上的自定义标记会被连带清掉，属性则不受影响。

两个必须单独处理的坑：

1. **Monaco 编辑器**锁死在浅色 `vs` 主题，32 个语法令牌色（`.mtk1` ~ `.mtk32`）是硬编码的，改不了变量，只能逐个覆盖。
2. **题面代码块**用 Prism，颜色写在行内 `style="color: slategray"` 里，得靠属性选择器 `[style*='slategray']` 才能命中。

另外还有一批只带 `text-label-*` 而没有对应 `dark:` 变体的文字，是浅色主题的深灰，压在暖黑上对比度只有 1.2 —— 这类也单独兜底了。

## 文件结构

```
leetcode-night-theme/
├── manifest.json        # MV3 清单
├── icons/               # 16/32/48/128 图标
├── src/                 # 扩展本体
│   ├── themes.css       # ★ 调色板：四套主题各定义 ~30 个 token
│   ├── theme.css        # ★ 结构层：从 token 派生出全部力扣变量
│   ├── content.js       # 挂载/守护、遮罩、快捷键、设置同步
│   ├── popup.html       # 设置面板
│   ├── popup.css
│   ├── popup.js
│   └── background.js    # 快捷键命令、安装初始化
└── userscript/          # 油猴脚本
    ├── shell.js         # 外壳模板（控制逻辑 + 设置面板）
    ├── build.mjs        # 构建：把 theme.css 注入模板
    └── leetcode-night-theme.user.js   # ★ 生成的可安装文件
```

配色只定义在 `themes.css`（每套约 30 个变量），`theme.css` 负责派生。
**新增一套主题 = 在 themes.css 里加一个 40 行的块**，扩展和油猴版自动同步。

改完样式后执行：

```bash
node userscript/build.mjs
```

就会重新生成油猴脚本，两边的配色永远一致，不会走样。

> 注意：别直接改 `userscript/leetcode-night-theme.user.js`，它是构建产物，下次构建会被覆盖。
> 要改控制逻辑请改 `userscript/shell.js`。
